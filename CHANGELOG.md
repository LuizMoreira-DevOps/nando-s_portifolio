# Changelog

Todas as alterações relevantes deste projeto serão registradas
neste documento.

O projeto utiliza
[Semantic Versioning](https://semver.org/lang/pt-BR/).

## [Unreleased]

Versão em desenvolvimento: `0.10.0-alpha.1`.

### Adicionado

- Pipeline de integração contínua (CI).
- Pipeline de entrega e publicação (CD).
- Workflow de gerenciamento de releases.
- Configuração do Dependabot.
- Política de segurança do repositório.
- Template de Pull Request.

- Configuração de variáveis de ambiente.
- Configuração do Next.js para exportação estática.
- Padronização dos finais de linha.
- Proteção contra publicação acidental no npm.
- Geração de tipagens antes da validação do TypeScript.

### Planejado

- Versionamento dos arquivos da aplicação.
- Validação dos workflows.
- Revisão visual e responsiva.
- Primeira release e publicação.
